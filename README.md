# Tabletop Copilot

Советник по D&D 5e (2014): в кого превратиться друиду в этой ситуации, что подготовить кастеру.

Главный принцип — **LLM не может предложить нелегальный вариант**, потому что работает не по
памяти, а по списку, отфильтрованному детерминированными правилами из настоящего каталога SRD.
Цифры в ответе берутся из каталога, а не из текста модели.

## Экономия запросов

По умолчанию **LLM не вызывается вообще**: рейтинг с цифрами считается детерминированно,
мгновенно и бесплатно. Объяснение словами — отдельное действие, и только оно тратит запрос.
Ответы кэшируются по детерминированному ключу, кэш общий для всех пользователей.

## Установка

```bash
uv sync --group dev
uv run python -m tools.sync_catalog   # разовая загрузка каталога SRD
uv run streamlit run apps/ui.py
```

Для объяснений от LLM нужен ключ Gemini в `.env` и установленный экстра:

```bash
uv sync --group dev --extra llm
```

Без ключа приложение работает — просто без текстовых объяснений.

## Данные

Каталог — [Open5e](https://open5e.com) API, документ `srd-2014` (SRD 5.1, открытая лицензия):
98 зверей и 319 заклинаний. Загружается один раз в `data/catalog/`, дальше работает офлайн.
